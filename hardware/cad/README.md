# CAD

The arm is the open-source **TW2KA** design ([TW2KA on YouTube](https://youtube.com/@tw2ka644)); get the original parts from there.

This folder contains only **my own and modified parts**.

## Pen holder

![Pen holder](pen_holder_preview.png)

| | |
|---|---|
| File | [`pen_holder.3mf`](pen_holder.3mf) (print-ready project, opens in Bambu Studio / OrcaSlicer / PrusaSlicer) |
| Size | about 24 × 18 × 33 mm |
| Design | block with four mounting holes plus a centre hole on top (to the J6 flange) and a side bore that holds the pen |
| Why | lets the arm hold a pen for G-code drawing |

After mounting a pen, measure how far the **pen tip is below the flange** and **ahead of it**, and enter both in the controller's G-code drawing card (see [docs/07-drawing.md](../../docs/07-drawing.md)).
